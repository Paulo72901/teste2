# Amor & Mistério — Landing Page de Caixas Misteriosas

Landing page de alta conversão para o clube de assinatura bimestral de caixas misteriosas de lingerie e moda íntima feminina **Amor & Mistério**.

## ✨ Funcionalidades Principais

- **Design Exclusivo de Alta Costura**: Paleta noturna sedutora com Bordeaux (`#722F37`), Ouro Envelhecido (`#D3AF37`), Nude (`#E3BC9A`) e Preto Ônix (`#0A0507`).
- **Tipografia Nobre**: *Cormorant Garamond* nos títulos e *DM Sans* nos textos e botões.
- **Contador Regressivo**: Contagem regressiva em tempo real para encerramento das inscrições do ciclo bimestral vigente.
- **Tarja Infinita**: Animação contínua da esquerda para a direita com o logotipo oficial da marca.
- **Vídeo Central Imersivo**: Vídeo Vimeo em background de tela cheia, sem controles e com reprodução contínua em loop sem áudio.
- **Quiz de Medidas & Estilo Interativo**: Coleta medidas de **sutiã, calcinha, camisola e pijama**, preferências específicas de modelagem/sustentação, revela o arquétipo da cliente e permite **editar as medidas** a qualquer momento.
- **Checkout Seguro com Cobrança Recorrente**: Formulário humanizado com dados de identificação (Nome, CPF, Email, Telefone) e endereço completo (CEP, Estado, Cidade, Bairro, Rua, Número, Complemento, Ponto de referência), além de cartão com cobrança bimestral recorrente (sem travar o limite total).
- **Programa "Indique uma Amiga"**: Tela com imagem de fundo de alta atmosfera, gerador de link personalizado e compartilhamento direto no WhatsApp.

## 🚀 Como Executar Localmente

1. **Instalar dependências**:
   ```bash
   npm install
   ```

2. **Iniciar o servidor de desenvolvimento**:
   ```bash
   npm run dev
   ```
   Acesse `http://localhost:3000` no seu navegador.

3. **Gerar a build de produção**:
   ```bash
   npm run build
   ```
